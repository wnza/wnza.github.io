# 憨憨去水印 · 抖音无水印提取

一个可以直接打开使用的抖音视频 / 图集无水印提取网页。粘贴分享链接，一键提取，一键保存。

![界面预览](preview.png)

![视频解析结果](preview-result.png)

## 功能

- 支持抖音视频、图文 / 图集作品
- 视频输出无水印 MP4，保留原声
- 图集输出原图，可单张保存，也可一键打包 ZIP
- 一键粘贴、一键清除、一键提取、一键保存
- 视频在线预览，图集灯箱预览、左右切换
- 自动识别分享口令里的链接、短链接、长链接
- 纯前端单文件，无登录、无后端、无数据库
- 适配桌面端与手机端

## 直接使用

双击 `index.html`，用 Chrome / Edge 打开即可。

如果浏览器限制本地文件的剪贴板读取，可以：

1. 双击 `start.bat` 启动本地服务，再访问 `http://127.0.0.1:8787/`；
2. 或手动运行：

```bash
node serve.mjs
```

需要 Node.js 18 及以上。本地服务不是必须的，但它能让剪贴板读取和文件保存更稳定。

> 不需要电脑一直开着：直接打开 `index.html` 时没有本地服务在跑；只有你用 `start.bat` 起局域网地址给手机访问时，电脑才需要开着。把 `index.html` 放到任意静态托管后，手机和别的电脑随时都能打开，不依赖你的电脑。

也可以使用任意静态服务器：

```bash
python -m http.server 8787
# 然后打开 http://127.0.0.1:8787/
```

## 使用步骤

1. 在抖音作品页点「分享」→「复制链接」，或复制整段分享口令。
2. 回到页面，点「粘贴」，再点「一键提取」。
3. 视频点「保存视频」；图集点「保存原图」或「保存全部 N 张」。
4. 手机端会自动跳过文件选择器，直接下载到浏览器下载目录；桌面端支持文件选择器时会先让你选择保存位置。

快捷键：`Ctrl + Enter` / `Cmd + Enter` 提取。

## 实现说明

- 页面本身是单文件 `index.html`，样式和脚本都内联，不需要构建。
- 解析通过公开的第三方解析接口完成，链接仅用于本次解析，页面不保存历史记录。
- 媒体文件由浏览器直接从抖音 CDN 获取；图集 ZIP 在浏览器本地生成。
- 保存时桌面端优先使用 File System Access API（流式写入，适合大视频）；手机端直接走 Blob 下载，避免部分手机浏览器的系统文件选择器取消/不落地问题。
- 视频预览被限制在卡片圆角容器内，移动端播放时不会溢出边框。
- 页面不包含统计、广告、登录或账号相关代码。

## 部署到 GitHub Pages

1. 把 `index.html` 上传到 GitHub 仓库；
2. 在仓库 `Settings → Pages` 里选择部署分支和目录；
3. 等 Pages 构建完成后访问生成的地址。

更新页面后如果还看到旧版本或视频预览失败，按 `Ctrl + F5` 强制刷新，并等 1～2 分钟让 Pages 缓存更新。

> 页面里的 `<meta name="referrer" content="no-referrer">` 不能删除。抖音 CDN 会校验 `Referer`，GitHub Pages 默认会带上 github.io 来源，导致视频返回 403；这段设置让媒体请求不带来源，视频预览和保存才能正常。

- 仅限个人学习、收藏与备份，请尊重原作者版权，未经授权不要商用或二次传播。
- 作品被删除、设为私密、仅好友可见或链接过期时，解析会失败。

- 第三方解析接口有频率限制，短时间大量提取可能失败，稍后再试即可。
